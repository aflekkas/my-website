# Portfolio 👋

My personal site, built with [Astro](https://astro.build) and Tailwind CSS. It ships as fully
static HTML with no client-side JavaScript.

## Where can I see it? 🤔

You can check it out here [www.alexandroslekkas.com](https://www.alexandroslekkas.com)!

## Development

```sh
pnpm install
pnpm dev      # local dev server
pnpm build    # static build into dist/
pnpm preview  # serve the built site
```
